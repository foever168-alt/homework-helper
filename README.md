# 作業收件小幫手

这是一个可部署到 GitHub Pages 的手机优先三阶段网页：小老师在同一个区块内点麦克风、语音或点选座号、返回上一笔并结束登记，接着在结果页确认缺交名单，最后从汇出页查看纪录与同步状态。座号会依画面宽度自动调整栏数，避免在语音工具列与座号区之间来回卷动。26 号固定标示为休学；说出「刚刚念错了」或按返回图示可撤销尚未送出的上一轮操作。

「收作業人」可填寫座號或文字，也可用同一個麥克風說「收作業人 12號」或「收作業人 王小明」。作業名稱上限為 12 個字，可手動輸入或說「作業名稱 數學習作」。

一般收件可按「本次不用收作業」後點選特定座號，或說「本次不用收作業 3 號、8 號」。這些學生不會被計入缺交，結果頁會分開顯示「缺交座號」與「本次不用收作業」；若標記錯誤，可在標記模式中再點一次座號，或使用返回上一筆。

「分段輪收」模式固定分為三輪：1～10 號、11～20 號、21～33 號（26 號休學，不列入人數）。三個分段按鈕可隨時手動點選；畫面仍顯示全部座號，但非本輪座號會以灰紫色標示並禁止點選，也不計入缺交。每輪可輸入不同作業名稱；成功送出後會保留收作業人、清空作業名稱與座號，並自動切到下一輪。第三輪完成後會自動回到第一輪。每一輪都是獨立紀錄，因此送出任一輪後即可結束當日收件。

頁面另有「補交登記」模式：畫面會向後台取得前 1～3 日曾登記的作業，以「日期｜作業名稱｜收件範圍」顯示。點選後會同時帶入原收件日期、作業名稱與原收件範圍，避免同名作業或分段輸入錯誤；仍可手動輸入。填寫收作業人後，再點選或念出補交座號。後台會把補交寫回原日期、同名作業與相同範圍的區塊，將學生狀態更新為「第 1／2／3 日補交」，並保留補交時間與收作業人；超過三日、找不到原作業或重複補登都會拒絕寫入。公開端點只回傳日期、作業名稱與收件範圍，不回傳學生姓名或繳交狀態。

## GitHub Pages

整个资料夹可直接上传到 GitHub 仓库。仓库内已附 GitHub Actions：在仓库的 **Settings → Pages → Build and deployment** 选择 **GitHub Actions**，之后每次推送到 `main` 都会自动发布 `dist`。网页不含学生姓名或成绩资料。

## Google Sheets 后台

1. 在 Google Drive 确认或建立「成绩」资料夹，复制资料夹网址中 `/folders/` 后面的 ID。
2. 新建 Google Apps Script 专案，把 `gas/Code.gs` 贴进去。
3. 在 Apps Script 的 **专案设定 → 指令码属性** 新增 `FOLDER_ID`，值为「成绩」资料夹网址中 `/folders/` 后面的 ID。
4. 在同一处新增 `ROSTER_SPREADSHEET_ID`，值为学生名单 Google Sheet 的文件 ID；再新增 `ROSTER_SHEET_NAME`，值为 `原班名單`。
5. 部署为 Web App：执行身分选「我」，存取权限设为可让公开网页直接呼叫的「所有人」。
6. 把部署后的 `/exec` URL 写入 `dist/index.html` 的 `GAS_WEB_APP_URL` 常数，然后重新发布 GitHub Pages。学生装置不需要另行设定或登入。

第一次按「汇出并送出」时，Apps Script 会在「成绩」资料夹自动建立一份固定的 `收作业小老师收作业`，并把档案 ID 存入指令码属性 `DATA_SPREADSHEET_ID`。之后每次登记都写进同一个 Google Sheets：`总览` 会新增一笔索引，有登记的日期才会自动建立 `yyyy-MM-dd` 分页；同一天的多份作业放在同一分页，并依作业名称分成不同区块。每个区块包含收作业人、开始与完成时间，以及 1–33 号的姓名和缴交状态。补交会更新原区块与总览统计，不会另建日期分页。学生姓名只会由 Apps Script 在执行时从私人名单读取，不会写入公开网页源码。

分段輪收仍寫入同一份 Google Sheets：總覽中的作業名稱會附上範圍，例如「桃花源記學習單｜1～10號」；日期分頁的作業區塊會增加「收件範圍」，非本輪座號則記為「本輪不收」。補交時須選擇相同的原收件範圍，後台才會更新正確區塊。

一般收件的免交座號在日期分頁會標示為「本次不用收」，總覽的座號摘要也會分開列出缺交與不用收的座號，不會把免交學生誤算為缺交。

## 隐私说明

不要把成绩资料夹 ID、名册试算表 ID、学生名单或登记资料提交到公开 GitHub 仓库。Web App URL 会随网页公开；这个部署模式没有访问码，任何取得端点的人都可能送出资料，因此后端会严格验证座号集合、作业名称与时间格式。学生姓名只保留在私人 Google Sheets 中，网页只在当前浏览器保存最近登记纪录作为失败时的本机备援。
